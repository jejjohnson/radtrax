# Atmosphere

The ideal-gas constants and number density (`gas`) and the air-mass factor
(`geometry`): the one implementation of each in radtrax.
`radtrax.spectroscopy.tables` and `radtrax.slab.config` re-export them.
`AtmosphericState`, AFGL profiles and hydrostatics arrive in Wave 3.

# Optics

`OpticalProperties`, the stage between opacity and the solver in
*radtrax · 3*: per-layer optical depth `τ (L, G)` on its wavenumber grid.
The single-scattering albedo and phase-function moments join it in v3 of the
roadmap, with defaults for a non-scattering atmosphere.
